# 📥 Telegram Watermark-Free Downloader Bot

A lightweight, high-performance Telegram bot built in Python that automatically extracts and downloads **TikTok** (watermark-free) and **Facebook** videos in HD quality simply by pasting a link.

---

## ✨ Features
* **TikTok (No Watermark):** Automatically strips watermarks for clean, high-quality downloads.
* **Facebook HD Support:** Bypasses low-quality compressed streams to fetch the highest available resolution.
* **Secure Configuration:** Uses environment variables (`.env`) to keep your bot tokens safe.
* **Easy to Run:** Built using `pyTelegramBotAPI` and powered by `yt-dlp`.
